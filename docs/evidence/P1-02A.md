## Limitations and next action

- The 403 PERMISSION_DENIED path is proven through a **test-only** URLconf (`organizations/tests/probe_urls.py`) using the shared helpers, because no management endpoint was assigned in P1-02A. The first real endpoint with a visible-but-forbidden action must add its own direct API test.
- Throttle cache is per-process LocMem: with 2 gunicorn workers the effective limit is up to 2×. Throttle state is lost on restart.
- New env var `DJANGO_TRUSTED_PROXY_HOSTS` (default `proxy`) is not yet listed in `.env.example` (not owned). Calls that bypass the proxy (web container → `api:8000`) share that peer's IP bucket, which only affects future server-side login calls.
- With 2 gunicorn workers and LocMem, the live 429 at attempt 21 means those requests landed in one worker's bucket. The documented bound is still up to 2×.
- Accepted risk (ADR 0003): targeted login lockout through the per-account throttle.
- `DEFAULT_ORGANIZATION_SLUG` defaults to `demo`; `.env.example` (not owned) does not list `DJANGO_DEFAULT_ORGANIZATION_SLUG`. The P1-02B seed command must create its organization with this slug, or the coordinator adds the variable to `.env.example`.
- With `DJANGO_DEBUG=1` (local), Django still serves its HTML technical 404 for non-`/api/v1/` paths; API paths are always JSON via the catch-all.
- `CUSTOMER` "own records" scoping has no data yet (no quotes in P1); `scope_to_organization`/`get_scoped_object_or_404` are provided for P3.
- Next action: coordinator acceptance. Coordinator adds `DJANGO_TRUSTED_PROXY_HOSTS` and `DJANGO_DEFAULT_ORGANIZATION_SLUG` to `.env.example` if desired, decides on item 7 (Dockerfile owner), and hands `config/settings/base.py` and `config/urls.py` to P1-02B.
