# @hardware-store/api-client

Typed client for `contracts/openapi.yaml` (source of truth, read-only here).

- `src/generated/openapi.d.ts` is generated by openapi-typescript 7.13.0 and committed. Do not edit it.
- `src/client.ts` is a thin openapi-fetch 0.17.0 wrapper; `src/errors.ts` interprets the ADR 0003 error envelope. No business rules (permissions, prices, stock) belong in this package.

Commands (run from the repository root through the pinned Node image):

```sh
infra/local/node.sh npm run api-client:generate   # rewrite generated types after a contract change
infra/local/node.sh npm run api-client:check      # regenerate-and-diff; exit 1 if stale
```
